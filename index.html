     Configuración
    
    
    Para enviar tareas directamente a Google Tasks, necesitas un Client ID de Google. Es gratuito y se configura en 5 minutos.
    

    
    
      ¿Cómo obtener el Client ID?
    
      1. Ve a console.cloud.google.com
    
      2. Crea un proyecto → APIs y Servicios → Credenciales
    
      3. Crea una ID de cliente OAuth 2.0 (tipo: Aplicación Web)
    
      4. Añade https://nana-asoc.github.io como origen autorizado
    
      5. Activa la Google Tasks API en "Biblioteca"
    
      6. Copia el Client ID y pégalo aquí abajo.
